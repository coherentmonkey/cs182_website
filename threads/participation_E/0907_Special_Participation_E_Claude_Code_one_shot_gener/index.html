● Homework 12 Overview

  This is a Berkeley CS182 Deep Learning assignment with two problems.
  Here's a summary with focus on the VAE portion:

  ---
  Problem 1: Variational Autoencoder (VAE) — The main VAE work

  Goal: Build a generative model for MNIST digits using variational
  autoencoders.

  Key implementation tasks:

  1. Reparameterization Trick (utils.py:41-42)
    - Implements sample_gaussian(m, v) to enable gradient flow through
  stochastic sampling
    - Formula: z = μ + ε·√σ² where ε ~ N(0,I)
  2. Negative ELBO (models/vae.py:24-60)
    - The core VAE loss function: NELBO = KL divergence + Reconstruction 
  loss
    - KL term: measures how far encoder distribution q(z|x) is from prior
  p(z)
    - Reconstruction: negative log-likelihood (Bernoulli) of decoded output

  Architecture:
  - Encoder: 784 → 300 → 300 → 2×z_dim (produces mean & variance)
  - Decoder: z_dim → 300 → 300 → 784
  - Latent dim: 64 (default)

  Files:
  | File                        | Purpose                          |
  |-----------------------------|----------------------------------|
  | vae/q_vae.ipynb             | Main notebook to run             |
  | vae/cs182hw12/models/vae.py | VAE model (ELBO implementation)  |
  | vae/cs182hw12/models/nns.py | Encoder/Decoder networks         |
  | vae/cs182hw12/utils.py      | Utility functions (sampling, KL) |

  ---
  Problem 2: MAML Classification — Meta-learning

  Implements Model-Agnostic Meta-Learning for binary classification with
  logistic loss.

  Key Learning Points Covered

  1. Why VAEs work: The ELBO gives us a tractable objective when we can't

  2. Reparameterization Trick: z = μ + ε·σ where ε ~ N(0,1) - makes sampling
