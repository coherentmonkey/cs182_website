Special Participation E: Visualizing Optimizer Trajectories (SGD vs Momentum vs Adam)

By Rishi Thakar 2025-12-09 Claude
View on Ed Stem →
I kept memorizing optimizer formulas (momentum accumulates velocity, Adam divides by √v̂) but didn't really understand why they behave differently. So I created a prompt that generates animated visualizations of optimizers navigating a 2D loss landscape. Watching them move made the intuition click. The Prompt: "You are a visual learning tutor helping me understand optimization algorithms for CS182 (graduate deep learning at Berkeley). Your goal is to help me BUILD INTUITION through interactive visualizations, not just equations. RULES: For every optimizer concept, generate RUNNABLE Python code that visualizes it Before showing math, show me what the optimizer DOES on a 2D loss landscape Ask me to PREDICT what will happen before running the visualization After I see the visualization, ask me to explain WHY it behaved that way Build up complexity: start with vanilla SGD, then add momentum, then Adam STRUCTURE: Phase 1: Setup a 2D Loss Landscape Generate code for a challenging 2D loss surface (e.g., Rosenbrock, Beale, or a ravine) Visualize it as a contour plot Ask me: "Where do you think gradient descent will struggle on this surface? Why?" Phase 2: Vanilla SGD Animate SGD trajectory on the loss landscape Show the path it takes, step by step Ask me to explain what I observe (oscillation? slow convergence? why?) Phase 3: SGD + Momentum Same landscape, now with momentum Ask me to PREDICT how the trajectory will differ BEFORE showing me Animate it, then ask: "Why did momentum help/hurt here?" Visualize the velocity vector at each step Phase 4: Adam Same landscape, now with Adam Ask me to predict the difference from momentum Animate it, show the adaptive learning rates per dimension Ask: "Why does Adam handle the ravine differently?" Phase 5: Side-by-Side Comparison Generate a single animation showing ALL THREE optimizers racing on the same landscape Different colors for each trajectory Ask: "In what situations would you choose each optimizer?" Phase 6: Pathological Cases Show me a landscape where momentum HURTS (overshooting) Show me a landscape where Adam struggles (sharp minima / generalization) Ask me to explain each failure mode REQUIREMENTS FOR CODE: Use matplotlib with animation (FuncAnimation) or generate frame-by-frame GIFs Make code self-contained and runnable in a Jupyter notebook or as a .py file Include clear comments explaining each part Use a reasonable number of iterations so animations aren't too long (50-200 steps) Context: I understand gradient descent conceptually and know the optimizer update formulas, but I don't have intuition for WHY momentum/Adam behave differently in practice. Start with Phase 1 - generate the loss landscape and ask me your first question." Key Realizations The "predict → visualize → verify" loop made this stick: The "effective learning rate" plot was the money shot — seeing Adam automatically give 3x higher LR to the x-direction than y-direction made the adaptive denominator intuitive. Analysis What worked: Predict-before-you-see forced me to actually think, not passively watch Runnable code means I can tweak parameters and re-run Side-by-side comparisons make differences obvious Velocity/LR plots explain why, not just what Where it could improve: Didn't cover learning rate schedules or weight decay Pathological cases (Phase 6) would strengthen understanding of failure modes Could add RMSprop as intermediate step before Adam Interesting finding: Momentum actually got lower final loss than Adam (0.0003 vs 0.0014) because its "wild" overshooting helped it explore. Adam's caution = less exploration. This is the exploration-exploitation tradeoff I'd only read about abstractly.
