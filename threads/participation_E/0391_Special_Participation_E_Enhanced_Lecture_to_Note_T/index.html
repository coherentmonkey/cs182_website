I added new features to the existing (lecture slide + lecture transcript) --> (LaTeX notes) pipeline. This work builds on #301 and makes these main improvements: Incorporates direct quotations from our recommended textbook: Understanding Deep Learning for cross-referencing and introducing potentially different POVs. Includes accurate references to precise pages in the textbook for relevant key concepts to encourage further exploration and improve integration between the notes and the textbook. Encourages Gemini to recreate figures and diagrams with LaTeX, when possible--very helpful for visualizing abstract concepts. Motivation Classes like the old EECS 16A/B and CS 70 were known for excellent staff-written notes, which made the material organized and accessible, and greatly supported students in self-learning. On the other hand, classes like CS 170 and EECS 126 placed a greater emphasis on their recommended textbook, which were even more excellent sources of knowledge, but could sometimes feel overwhelming due to their high information density. Both the succinct class notes and the chunky textbooks helped us self-learn, but in different ways. In a Deep Learning course, where the field evolves almost faster than we can keep up, self-learning is even more essential. So here, I attempt to amalgamate the notes and the textbook to achieve an optimal balance between accessibility and information quality/density. Details The pipeline still intakes a lecture slides pdf that gets converted to images to enable visual information extraction, and a lecture transcript of the corresponding lecture that is downloadable from YouTube, but now also takes in the textbook pdf that is uploaded as a file. Feel free to compress the pdf, if needed. From my testing, even extreme compression, given words are still easily discernible, works fine. The pipeline needs a Gemini API, and the final typeset notes can be rendered by compiling the lecture_notes.tex output file with a command like pdflatex lecture_notes.tex. import time
import os
from io import BytesIO
from google import genai
from google.genai.types import Part
from pdf2image import convert_from_path
from tqdm import tqdm


def pdf_to_images(pdf_path):
    print(f"Converting lecture slides to images: {pdf_path}")
    images = convert_from_path(pdf_path, dpi=300)
    print(f"Successfully converted {len(images)} pages")
    return images


def read_transcript(txt_path):
    with open(txt_path, 'r', encoding='utf-8') as f:
        content = f.read()
    return content


def image_to_bytes(image):
    buffered = BytesIO()
    image.save(buffered, format="PNG")
    return buffered.getvalue()


def upload_textbook(client, path):
    """Uploads the textbook PDF to the Gemini File API."""
    # Check if already uploaded to avoid redundancy in repeated runs (optional optimization)
    # Note: for simplicity here, we upload every time.
    print(f"Uploading textbook: {path}...")
    try:
        file_ref = client.files.upload(file=path)
        print(f"Uploaded file '{file_ref.display_name}' as: {file_ref.name}")
        
        while file_ref.state.name == "PROCESSING":
            print(".", end="", flush=True)
            time.sleep(2)
            file_ref = client.files.get(name=file_ref.name)
            
        if file_ref.state.name == "FAILED":
            raise ValueError(f"File upload failed: {file_ref.error.message}")
            
        print(f"\nTextbook is ready :) (State: {file_ref.state.name})")
        return file_ref
    except Exception as e:
        print(f"\nError during file upload :( : {e}")
        raise


def call_gemini_api(slide_images, transcript, textbook_path, GEMINI_API_KEY):
    client = genai.Client(api_key=GEMINI_API_KEY)
    
    # 1. Upload Textbook
    textbook_file = upload_textbook(client, textbook_path)

    # 2. The Mega-Prompt
    prompt = """
    **Role:** You are an expert academic note-taker and technical illustrator for a CS 182 Deep Neural Networks course.

    **Inputs:** 1. Handwritten Lecture Slides (Images attached)
    2. Lecture Transcript (Text below)
    3. Textbook: "Understanding Deep Learning" by Simon J.D. Prince (PDF uploaded)

    **Task:** Create a comprehensive, highly technical, typeset LaTeX article that synthesizes these inputs.

    **Requirements:**
    **1: Textbook Integration (Citations)**
    - Cross-reference lecture concepts with the Prince textbook.
    - Add margin citations for specific chapters/pages where concepts are defined, telling readers to 'refer to that place in the textbook for more info'.
    - Format: `\\marginpar{\\footnotesize \\textit{Prince, Ch X, pg Y}}`.

    **2: Textbook Quotes**
    - For every big concept, include important at least one quote accurately from the textbook, written in a special quote block in latex.
    - Include the precise location (page number, chapter) from where the quote was selected.
    - Quotes should be highly relevant to the notes' topics.
    
    **CRITICAL CONSTRAINT:** 
    - DO NOT reference external files (e.g., do NOT include files ending in `.png`, `.dat`, etc. since those won't exist on the user's end).
    - Users will compile the latex code in a clean directory so any references to other files will fail.

    **Formatting Requirements:**
    - **Output ONLY raw and LaTeX code.** No markdown ticks (```latex).
    - **Structure:** Provide the FULL document, starting with `\\documentclass{article}` and ending with `\\end{document}`.
    - **Preamble:** Include these packages:
        - `\\usepackage[a4paper, margin=1.5in, marginparwidth=1.2in]{geometry}` (Wide margins for notes)
        - `\\usepackage{tikz}` (For coded diagrams)
        - `\\usepackage{pgfplots}` (For math plots)
        - `\\pgfplotsset{compat=1.18}`
    - **Content:** Clean up the transcript into professional academic English. Use `\\section` and `\\subsection` to organize topics logically based on the slides.

    **Lecture Transcript:**
    """ + transcript
    
    # 3. Construct Request
    # Context Order: Textbook -> Slides -> Prompt Instructions -> Transcript (at end of prompt)
    contents = [textbook_file] 
    
    print("Attaching slide images to context...")
    # We select a subset of slides if there are too many to avoid overloading, 
    # but for a standard lecture, 20-30 slides is usually okay for Gemini Pro.
    for image in tqdm(slide_images):
        image_bytes = image_to_bytes(image)
        contents.append(
            Part.from_bytes(
                data=image_bytes,
                mime_type="image/png"
            )
        )
    
    contents.append(prompt)
    
    print("\nCalling Gemini API...")

    # I found that keeping temperature lower helps ensure accurate math.
    response = client.models.generate_content(
        model="gemini-2.5-pro",
        contents=contents,
        config=genai.types.GenerateContentConfig(
            temperature=0.2 
        )
    )

    print("Successfully received response from Gemini API")
    return response.text


def clean_and_save_latex(content, output_path):
    content = content.strip()
    if content.startswith("```latex"):
        content = content[8:].strip()
    elif content.startswith("```tex"):
        content = content[6:].strip()
    elif content.startswith("```"):
        content = content[3:].strip()
    if content.endswith("```"):
        content = content[:-3].strip()
        
    # Additional validation to ensure Gemini followed instructions and provided a full doc
    if "\\documentclass" not in content or "\\end{document}" not in content:
        print("Warning: Generated content does not appear to be a complete LaTeX document. Saving anyway for inspection.")

    with open(output_path, 'w', encoding='utf-8') as f:
        f.write(content)
    print(f"\nSuccessfully saved complete LaTeX notes to {output_path}")
