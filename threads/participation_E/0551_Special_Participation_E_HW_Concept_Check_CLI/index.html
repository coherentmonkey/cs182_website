Special Participation E: HW Concept Check CLI

By Aryan Bansal 2025-12-07 Unknown
View on Ed Stem →
Sometime when I look at a homework question, I don't know exactly where to start. Although the struggle of interpreting a question is good, a reminder/concept check seems like it could be helpful. At the same time, asking a chat application makes it hard to not overshare and delegate work. Therefore, I created a simple CLI that presents a series of conceptual questions about homework questions. The CLI makes it easy to select and a homework no. and part no. The generated question can be responded to via the cmd line or a hint can be requested. When a response is submitted, it is evaluated against the expected answer, and a follow up question will be presented to fill in the gaps. An LLM is necessary for the task of grading free-response answers effectively. I first created an ingestion script that iteratively takes every homework and uses an effective system prompt to generate the bank of questions and write to .json files. This does not have to be run again. The main script "concept_cli_app.py" launches the GUI. The script is bring your own key (export OPENAI_API_KEY=sk...) Below I've attached the zip file of the repo and an annotated example interaction. The README has proper instructions (create env, export key, run it).

Homework hw1 - Question 3 - Concept check 1/3
------------------------------------------------------------
Conceptual question:
How does adding momentum modify the convergence behavior of gradient descent, particularly in terms of allowable learning rates and convergence speed?

Commands: [h] hint  [a] ideal answer  [r] respond  [n] next  [p] previous  [b] back to question menu  [q] quit
> r

Type your answer (single line, be concise):
> momentum enables faster convergence by taking larger steps when their is a decisive gradien step. at the same time, the range of allowable learning rates is the same.   

Step 1 evaluation: partially_correct
Feedback: The student correctly notes that momentum enables faster convergence by taking larger steps when the gradient direction is consistent. However, they incorrectly state that the range of allowable learning rates remains the same; in fact, momentum often allows for larger learning rates without divergence due to its smoothing effect.

Follow-up question:
Can you explain how momentum helps to dampen oscillations during gradient descent?
Your answer to the follow-up (press Enter to skip and end evaluation):
> momentum is a rolling average in a sense. thus, if the sign of the gradient is changing heavily, the net effect will cancel out in some sense

Step 2 evaluation: partially_correct
Feedback: The student correctly identifies that momentum acts like a rolling average and can reduce the effect of rapidly changing gradient signs, which helps dampen oscillations. However, the answer does not explicitly mention how this allows for larger learning rates or accelerates convergence speed, which are key aspects of the ideal answer.

Follow-up question:
Can you explain how using momentum allows for larger learning rates and speeds up convergence compared to standard gradient descent?
Your answer to the follow-up (press Enter to skip and end evaluation):
> Larger gradients for a similar reason as above. The learning rate is not purely dependent on the gradient in the current timestamp.

Step 3 evaluation: partially_correct
Feedback: The student correctly notes that momentum involves averaging gradients over time and that the update is not solely dependent on the current gradient. However, the explanation is vague and does not clearly connect how this averaging stabilizes updates, allows larger learning rates, or accelerates convergence by damping oscillations and improving conditioning.

Commands: [h] hint  [a] ideal answer  [r] respond  [n] next  [p] previous  [b] back to question menu  [q] quit

Ideal answer:
Momentum averages gradients over iterations, which can stabilize updates and allow for larger learning rates without causing divergence. This smoothing can accelerate convergence by effectively damping oscillations and improving conditioning, enabling faster progress compared to standard gradient descent.
