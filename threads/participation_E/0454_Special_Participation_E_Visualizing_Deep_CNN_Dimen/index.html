Special Participation E: Visualizing Deep CNN Dimensions & Architecture with Gemini3Pro and Manim

By Tin Yau 2025-12-04 Gemini
View on Ed Stem →
I've always found the dimensional transformations in CNNs (tensors changing shapes) to be the hardest part to visualize mentally. Inspired by the 3b1b approach, I utilized Gemini to build a Manim script that visualizes the complete lifecycle of a signal in a Deep CNN, specifically focusing on the concepts from Lecture 8. The Workflow I fed the lecture slides to Gemini and asked it to generate a script that explains the mathematical justification for CNNs visually. Instead of generic animations, I prompted it to focus on specific "Core Topics" derived from the lecture notes. Topic Focus Prompt Here is the prompt logic I used to generate the scene: "Create a comprehensive animation named DeepCNNLecture that visualizes: Sparsity & Locality: Contrast Fully Connected layers with Convolutional layers to show parameter efficiency. 2. Volumetric Convolution: Visualize how an $H \times W \times 3$ RGB input interacts with $3 \times 3 \times 3$ filters 2. 3. Spatial Arithmetic: Visually prove how Zero-Padding preserves dimensions 3and how Stride drives downsampling 4. 4. Deep Architecture: Build a 2.5D VGG-style stack to show the trade-off between spatial size and depth, ending with a Flatten operation 5." The Result The script generates a continuous 7-part video. You can build it using the attached file: manim -pqh CNN_lecture.py (I have attached the generated video and the source code below). Benefits & Insights Through this visualization process, I realized several key pedagogical advantages: Enhanced Intuitive Understanding: The animation provides a tangible way to grasp the otherwise abstract tensor transformations and feature map evolutions. Compared to static text or formulas 6, visual motion helps learners develop spatial reasoning intuition, making it easier to see how inputs progressively shrink, deepen, and flatten through the network. Bridging Cross‑Disciplinary Communication: These visualizations make it possible for learners without a strong mathematical background to comprehend key structural ideas like "Volumes" and "Receptive Fields". By reducing reliance on symbolic derivations, the video serves as a language‑agnostic medium for instruction. Improved Pedagogical Engagement: Animating the "flow of a signal through the network" turns an abstract lecture into a more interactive experience. The dynamic color transitions and step-by-step highlights (e.g., showing exactly which pixels contribute to a convolution sum) significantly boost attention on the core mechanics. Technical Reflections 2.5D vs 3D: True 3D rendering in Manim is computationally heavy. I prompted Gemini to create "Pseudo-3D" layers (stacking 2D shapes with offsets) to visualize the Depth of the feature maps efficiently. Debugging: LLMs often confuse Manim parameters (e.g., passing font_size to next_to methods). I iteratively refined the code to decouple object creation from positioning to fix these TypeErrors.

from manim import *
import numpy as np

def create_stacked_grid(rows, cols, num_channels, cell_size=0.5, spacing=0.2):
    channels = VGroup()
    colors = [RED, GREEN, BLUE]
    
    for k in range(num_channels):
        grid = VGroup()
        color = colors[k % 3]
        for r in range(rows):
            for c in range(cols):
                sq = Square(side_length=cell_size, color=color, fill_opacity=0.2)
                sq.move_to(np.array([c*cell_size, -r*cell_size, 0]))
                grid.add(sq)
        
        shift_vec = np.array([k*spacing, k*spacing, 0])
        grid.shift(shift_vec)
        channels.add(grid)
        
    return channels

class DeepCNNLecture(Scene):

        self.intro_motivation()

        self.padding_demonstration()

        self.deep_architecture()

    def intro_motivation(self):
        title = Text("Lecture 8: Deep CNNs", font_size=48)
        subtitle = Text("From Fully Connected to Sparse & Deep", font_size=32, color=BLUE)
        subtitle.next_to(title, DOWN)
        
        self.play(Write(title), FadeIn(subtitle))
        self.wait(1)
        self.play(FadeOut(title), FadeOut(subtitle))
        
        grid = VGroup(*[Square(side_length=0.2, color=GRAY, stroke_width=1) for _ in range(100)])
        grid.arrange_in_grid(10, 10, buff=0)
        grid.move_to(LEFT * 3)
        
        hidden = VGroup(*[Dot(radius=0.08, color=GREEN) for _ in range(10)]).arrange(DOWN, buff=0.3)
        hidden.move_to(RIGHT * 3)
        
        edge_group = VGroup()
        for i in range(20): 
            for h in hidden:
                l = Line(grid[i].get_center(), h.get_center(), stroke_width=0.1, color=GRAY, stroke_opacity=0.5)
                edge_group.add(l)
        
        txt_fc = Text("Fully Connected: Too Many Parameters!", font_size=24, color=RED)
        txt_fc.to_edge(UP)
        
        self.play(Create(grid), Create(hidden))
        self.play(Create(edge_group), run_time=2)
        self.play(Write(txt_fc))
        self.wait(1)
        
        txt_conv = Text("Convolution: Local Connectivity (Locality)", font_size=24, color=GREEN)
        txt_conv.to_edge(UP)
        
        local_edges = VGroup()
        target_h = hidden[4]
        center_indices = [33,34,35, 43,44,45, 53,54,55]
        
        rect = SurroundingRectangle(VGroup(*[grid[i] for i in center_indices]), color=YELLOW)
        
        for i in center_indices:
            l = Line(grid[i].get_center(), target_h.get_center(), stroke_width=2, color=YELLOW)
            local_edges.add(l)
            
        self.play(
            FadeOut(edge_group),
            Transform(txt_fc, txt_conv),
            Create(rect),
            Create(local_edges)
        )
        self.wait(2)
        self.clear()

    # --- Part 2 ---
    def basic_convolution(self):
        title = Text("Recap: 2D Convolution", font_size=36)
        title.to_edge(UP)
        self.add(title)
        
        grid = VGroup(*[Square(side_length=0.6, color=BLUE) for _ in range(25)]).arrange_in_grid(5, 5, buff=0)
        grid.move_to(LEFT * 2)
        
        kernel_rect = Square(side_length=0.6*3, color=YELLOW, stroke_width=4)
        kernel_rect.move_to(grid[0].get_center() + np.array([0.6, -0.6, 0]))
        
        out_grid = VGroup(*[Square(side_length=0.6, color=GREEN) for _ in range(9)]).arrange_in_grid(3, 3, buff=0)
        out_grid.move_to(RIGHT * 3)
        
        arrow = Arrow(grid.get_right(), out_grid.get_left(), color=WHITE)
        
        # 使用 Text 替代 MathTex 避免 LaTeX 错误
        formula = Text("y = sum(x * w) + b", font_size=24)
        formula.next_to(arrow, UP)
        
        self.play(Create(grid), Create(out_grid), GrowArrow(arrow), Write(formula))
        self.play(Create(kernel_rect))
        
        centers = [
            grid[0].get_center() + np.array([0.6, -0.6, 0]),
            grid[1].get_center() + np.array([0.6, -0.6, 0]),
            grid[2].get_center() + np.array([0.6, -0.6, 0]),
        ]
        
        for i, center in enumerate(centers):
            self.play(kernel_rect.animate.move_to(center), run_time=0.3)
            self.play(out_grid[i].animate.set_fill(GREEN, opacity=0.5), run_time=0.2)
        
        self.wait(1)
        self.clear()

    # --- Part 3 ---
    def rgb_convolution(self):
        title = Text("Multi-Channel (RGB) Convolution", font_size=36)
        title.to_edge(UP)
        
        input_volume = create_stacked_grid(5, 5, 3, cell_size=0.5, spacing=0.3)
        input_volume.move_to(LEFT * 4)
        
        input_label = Text("Input Volume (5x5x3)", font_size=20)
        input_label.next_to(input_volume, DOWN)
        
        kernel_volume = create_stacked_grid(3, 3, 3, cell_size=0.5, spacing=0.3)
        kernel_volume.move_to(LEFT * 0.5)
        
        kernel_label = Text("Kernel / Filter (3x3x3)", font_size=20)
        kernel_label.next_to(kernel_volume, DOWN)
        
        feature_map = VGroup(*[Square(side_length=0.5, color=WHITE) for _ in range(9)]).arrange_in_grid(3, 3, buff=0)
        feature_map.move_to(RIGHT * 4)
        
        output_label = Text("Feature Map (3x3x1)", font_size=20)
        output_label.next_to(feature_map, DOWN)
        
        conv_sym = Text("*", font_size=60).move_to((input_volume.get_right() + kernel_volume.get_left()) / 2)
        eq_sym = Text("=", font_size=60).move_to((kernel_volume.get_right() + feature_map.get_left()) / 2)
        
        self.play(Write(title))
        self.play(
            FadeIn(input_volume), Write(input_label),
            FadeIn(kernel_volume), Write(kernel_label),
            Write(conv_sym), Write(eq_sym),
            Create(feature_map), Write(output_label)
        )
        self.wait(1)
        
        explanation = Text("Sum across ALL channels", font_size=28, color=YELLOW)
        explanation.to_edge(DOWN)
        self.play(Write(explanation))
        
        highlights = VGroup()
        for i in range(3):
            layer = input_volume[i]
            indices = [0,1,2, 5,6,7, 10,11,12]
            for idx in indices:
                hl_sq = layer[idx].copy().set_color(YELLOW).set_stroke(width=3)
                highlights.add(hl_sq)
        
        self.play(Create(highlights))
        self.wait(0.5)
        
        lines = VGroup()
        lines.add(Line(highlights.get_right(), kernel_volume.get_left(), color=YELLOW))
        lines.add(Line(kernel_volume.get_right(), feature_map[0].get_left(), color=YELLOW))
        
        self.play(Create(lines))
        self.play(feature_map[0].animate.set_fill(GREEN, 0.8))
        
        self.wait(2)
        self.clear()

    # --- Part 4 ---
    def padding_demonstration(self):
        title = Text("Padding: Preserving Dimensions", font_size=36)
        title.to_edge(UP)
        self.play(Write(title))
        
        cell_size = 0.8
        padded_grid = VGroup()
        full_size = 6
        
        for r in range(full_size):
            for c in range(full_size):
                sq = Square(side_length=cell_size, stroke_width=2)
                if 1 <= r <= 4 and 1 <= c <= 4:
                    sq.set_color(BLUE).set_fill(BLUE, 0.5)
                else:
                    sq.set_color(GRAY).set_fill(GRAY, 0.2)
                    zero = Text("0", font_size=20, color=GRAY).move_to(sq.get_center())
                    sq.add(zero)
                
                sq.move_to(np.array([c*cell_size, -r*cell_size, 0]))
                padded_grid.add(sq)
                
        padded_grid.center()
        self.play(Create(padded_grid))
        
        label_pad = Text("Zero Padding (p=1)", font_size=24, color=GRAY)
        label_pad.next_to(padded_grid, DOWN)
        self.play(Write(label_pad))
        
        kernel = Square(side_length=cell_size*3, color=YELLOW, stroke_width=4)
        start_center = padded_grid[full_size + 1].get_center()
        kernel.move_to(start_center)
        
        txt_same = Text('"Same" Padding: Output size = Input size', font_size=24, color=YELLOW)
        txt_same.to_edge(DOWN)
        
        self.play(Create(kernel), Write(txt_same))
        self.wait(1)
        
        self.play(kernel.animate.shift(RIGHT * cell_size), run_time=0.5)
        self.wait(1)
        self.clear()

    def stride_demonstration(self):
        title = Text("Stride: Downsampling", font_size=36)
        title.to_edge(UP)
        self.add(title)
        
        cell_size = 0.6
        grid = VGroup(*[Square(side_length=cell_size, color=BLUE) for _ in range(49)]).arrange_in_grid(7, 7, buff=0)
        grid.move_to(LEFT * 3)
        
        kernel = Square(side_length=cell_size*3, color=YELLOW, stroke_width=4)
        start_pos = grid[8].get_center()
        kernel.move_to(start_pos)
        
        out_grid = VGroup(*[Square(side_length=cell_size, color=GREEN) for _ in range(9)]).arrange_in_grid(3, 3, buff=0.2)
        out_grid.move_to(RIGHT * 3)

        for r in range(0, 5, 2): 
            for c in range(0, 5, 2): 
                center_idx = (r+1)*7 + (c+1)
                target = grid[center_idx].get_center()
                self.play(kernel.animate.move_to(target), run_time=0.2)
                self.play(out_grid[output_idx].animate.set_fill(GREEN, 0.8), run_time=0.1)

        self.clear()

    def pooling_layer(self):
        title = Text("Pooling Layer (Max Pooling)", font_size=36)
        title.to_edge(UP)
        self.add(title)
        
        vals = np.random.randint(1, 9, (4,4))
        grid = VGroup()
        cell_size = 0.8
        for r in range(4):
            for c in range(4):
                s = Square(side_length=cell_size, color=BLUE)
                n = Text(str(vals[r][c]), font_size=24).move_to(s)
                g = VGroup(s, n).move_to(np.array([c*cell_size, -r*cell_size, 0]))
                grid.add(g)
        grid.center().shift(LEFT * 3)
        
        out_grid = VGroup(*[Square(side_length=cell_size, color=ORANGE) for _ in range(4)]).arrange_in_grid(2, 2, buff=0.2)
        out_grid.move_to(RIGHT * 3)
        
        self.play(Create(grid), Create(out_grid))
        
        colors = [RED, YELLOW, PURPLE, PINK]
        idx = 0
        for r in range(0, 4, 2):
            for c in range(0, 4, 2):
                group = VGroup()
                sub_vals = []
                for i in range(2):
                    for j in range(2):
                        flat_idx = (r+i)*4 + (c+j)
                        group.add(grid[flat_idx][0])
                        sub_vals.append(vals[r+i][c+j])
                
                self.play(group.animate.set_fill(colors[idx], 0.5), run_time=0.3)
                m = max(sub_vals)
                res = Text(str(m), font_size=24).move_to(out_grid[idx])
                self.play(Write(res))
                idx += 1
                
        self.wait(1)
        self.clear()

    def deep_architecture(self):
        title = Text("Deep CNN Architecture (VGG-Style)", font_size=40)
        title.to_edge(UP)
        
        subtitle = Text("Feature Extraction -> Flattening -> Classification", font_size=24, color=GRAY)
        subtitle.next_to(title, DOWN)
        
        self.play(Write(title), FadeIn(subtitle))
        self.wait(1)

        layers_config = [
            {"h": 3.5, "d": 0.2, "col": BLUE, "lbl": "Input\n224x224x3"},
            {"h": 3.0, "d": 0.6, "col": RED, "lbl": "Conv1\n55x55x96"},
            {"h": 1.5, "d": 0.6, "col": ORANGE, "lbl": "Pool1\n27x27x96"},
            {"h": 1.2, "d": 1.0, "col": RED, "lbl": "Conv2\n13x13x256"},
            {"h": 0.6, "d": 1.0, "col": ORANGE, "lbl": "Pool2\n6x6x256"},
        ]

        previous_layer = None
        layer_mobjects = []
        start_x = -5.5
        
        for i, config in enumerate(layers_config):
            layer_obj = self.create_3d_layer(
                height=config["h"], 
                width=0.2, 
                depth=config["d"], 
                color=config["col"]
            )
            
            if previous_layer is None:
                layer_obj.move_to(np.array([start_x, 0, 0]))
            else:
                layer_obj.next_to(previous_layer, RIGHT, buff=1.2)
            
            label = Text(config["lbl"], font_size=16, line_spacing=1.2)
            label.next_to(layer_obj, DOWN, buff=0.3)
            
            if previous_layer is not None:
                l_points = self.get_layer_corners(previous_layer, "right")
                r_points = self.get_layer_corners(layer_obj, "left")
                connectors = VGroup(
                    DashedLine(l_points[0], r_points[0], color=GRAY, stroke_opacity=0.3),
                    DashedLine(l_points[1], r_points[1], color=GRAY, stroke_opacity=0.3)
                )
                self.play(Create(connectors), run_time=0.5)
            
            self.play(FadeIn(layer_obj), Write(label), run_time=0.8)
            previous_layer = layer_obj
            layer_mobjects.append(layer_obj)
        
        brace_features = Brace(VGroup(*layer_mobjects), UP, buff=0.5)
        text_features = Text("Feature Learning", font_size=20)
        text_features.next_to(brace_features, UP)
        
        self.play(GrowFromCenter(brace_features), FadeIn(text_features))
        self.wait(1)

        flatten_vector = Rectangle(height=3.5, width=0.15, color=WHITE, fill_opacity=0.8)
        flatten_vector.next_to(previous_layer, RIGHT, buff=1.5)
        
        flatten_label = Text("Flatten", font_size=16)
        flatten_label.next_to(flatten_vector, DOWN, buff=0.3)
        
        last_3d_layer = layer_mobjects[-1]
        
        dots = VGroup(*[Dot(color=WHITE, radius=0.03) for _ in range(20)])
        dots.move_to(last_3d_layer.get_center())
        self.play(
            dots.animate.arrange(DOWN, buff=0.05).move_to(flatten_vector.get_center()),
            ReplacementTransform(last_3d_layer.copy(), flatten_vector),
            Write(flatten_label),
            run_time=1.5
        )
        self.remove(dots)
        
        arrow_flat = Arrow(last_3d_layer.get_right(), flatten_vector.get_left(), color=YELLOW, buff=0.1)
        self.play(Create(arrow_flat))

        fc1 = Rectangle(height=3.5, width=0.15, color=GREEN, fill_opacity=0.5)
        fc1.next_to(flatten_vector, RIGHT, buff=0.8)
        
        fc1_lbl = Text("FC\n4096", font_size=16)
        fc1_lbl.next_to(fc1, DOWN, buff=0.3)
        
        output = Rectangle(height=1.0, width=0.15, color=PURPLE, fill_opacity=0.8)
        output.next_to(fc1, RIGHT, buff=0.8)
        
        output_lbl = Text("Softmax\n1000", font_size=16)
        output_lbl.next_to(output, DOWN, buff=0.3)
        
        conn_fc = Line(flatten_vector.get_right(), fc1.get_left(), color=GRAY, stroke_opacity=0.5)
        conn_out = Line(fc1.get_right(), output.get_left(), color=GRAY, stroke_opacity=0.5)
        
        self.play(
            Create(fc1), Write(fc1_lbl), Create(conn_fc),
            Create(output), Write(output_lbl), Create(conn_out)
        )
        
        brace_class = Brace(VGroup(flatten_vector, fc1, output), UP, buff=0.5)
        text_class = Text("Classification", font_size=20)
        text_class.next_to(brace_class, UP)
        
        self.play(GrowFromCenter(brace_class), FadeIn(text_class))
        
        tracer = Dot(color=YELLOW, radius=0.08)
        tracer.move_to(layer_mobjects[0].get_left())
        
        path = VMobject()
        path.set_points_as_corners([
            layer_mobjects[0].get_center(),
            layer_mobjects[1].get_center(),
            layer_mobjects[2].get_center(),
            layer_mobjects[3].get_center(),
            layer_mobjects[4].get_center(),
            flatten_vector.get_center(),
            fc1.get_center(),
            output.get_center()
        ])
        
        self.play(
            MoveAlongPath(tracer, path),
            run_time=3,
            rate_func=linear
        )
        self.play(Flash(output, color=YELLOW, flash_radius=0.5))
        self.wait(2)

    def create_3d_layer(self, height, width, depth, color):
        front_face = Rectangle(height=height, width=width, color=color, fill_opacity=0.4, stroke_width=2)
        offset_vec = np.array([depth * 0.5, depth * 0.3, 0])
        
        c1 = front_face.get_corner(UR)
        c2 = front_face.get_corner(DR)
        c3 = c2 + offset_vec
        c4 = c1 + offset_vec
        side_face = Polygon(c1, c2, c3, c4, color=color, fill_opacity=0.6, stroke_width=1)
        
        c1 = front_face.get_corner(UL)
        c2 = front_face.get_corner(UR)
        c3 = c2 + offset_vec
        c4 = c1 + offset_vec
        top_face = Polygon(c1, c2, c3, c4, color=color, fill_opacity=0.5, stroke_width=1)
        
        return VGroup(front_face, side_face, top_face)

    def get_layer_corners(self, layer_group, side="right"):
        front_rect = layer_group[0]
        if side == "right":
            return [front_rect.get_corner(UR), front_rect.get_corner(DR)]
        else:
            return [front_rect.get_corner(UL), front_rect.get_corner(DL)]
