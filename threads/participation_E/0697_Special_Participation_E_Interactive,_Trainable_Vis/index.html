Special Participation E: Interactive, Trainable Visualization of the Attention Mechanism

By Neil Pattanaik 2025-12-08 Claude
View on Ed Stem →
With Claude 4.5 Opus, I built a fully trainable attention head visualization (with a slightly simplified architecture that does not contain a normalization layer or MLP). The purpose of this is for students visualize their own contrived/toy examples to understand how the attention mechanism operates. Try it out here: https://claude.ai/public/artifacts/eb7be4c4-ec9c-4398-a2d9-1e9c8559c17c The program allows you to choose the dimension of the embedding layer and define your own a vocabulary (in terms of pairs of text and embeddings, no tokenization here). The intention here is again to enable contrived examples that are intuition rich, such as the one below. Consider the following embeddings: cat: [1, 0, 0, 0.8] dog: [1, 0, 0, -0.8] likes: [0.3, 0.3, 1, 0] milk: [0, 1, 0, 0.8] water: [0, 1, 0, -0.8] Here, we choose (for demonstration purposes) to encode animal at index 0, drink at index 1, and an affinity at index 3. This is the default setup, so you can easily go try the following experiment! Observe initially that the attention head does not capture the affinity between cat/milk and dog/water. We will show how in two training steps, we can update the attention to recognize this toy example. Let's first train on the sequence "cat likes milk".
