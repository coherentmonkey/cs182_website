By Tyler Pham 2025-12-08 Gemini

I had Gemini 3 Pro build an interactive HTML site with Plotly to visualize how SGD, Momentum, and Adam navigate a difficult loss function because I often get confused about how changing their parameters like beta affects their end result. You can use sliding bars to tweak hyperparameters like the learning rate and beta values to see how it affects convergence. Even though I understand the intuition and motivation behind Momentum and Adam, I wanted to see more mathematical simulations where I could change the parameters and observe why Adam is so stable. Artifact (The HTML Site): Observations: When I asked the AI to explain the math inside the tool, it generated complex LaTeX equations. However, it failed to realize that a standard HTML browser cannot render LaTeX without a library like MathJax. It hallucinated a capability the file didn't have. I had to force it to rewrite the math using standard HTML entities. Gemini 3 Pro (which has Thinking) is a lot more concise compared to other models I've used like GPT 5 Thinking. When I asked it to explain more about the math behind Adam and Momentum, it's analysis was extremely short even when I told it to be detailed. This may have been due to already-high token count from the HTML. I noticed Momentum was consistently beating Adam in the simulation. I thought this was a bug. Gemini correctly explained that this is a feature, not a bug. In a noiseless deterministic function (like this simulation), Momentum acts like a race car without a speed limit. Adam, designed for real noisy data, normalizes the gradients, effectively enforcing a "speed limit" for stability. Initial Prompt: I want to create an interactive educational tool for my Deep Learning class to visualize the differences between SGD, Momentum, and Adam optimization.             <div class="math-section">
                <h3>1. Why Momentum beats SGD</h3>
                <p><strong>The Problem:</strong> In "ravines" (like this function), the surface is steep on the sides but flat along the bottom. SGD oscillates across the steep sides because the gradient &nabla;L is huge in the vertical direction.</p>
                <div class="formula">
                    v<sub>t</sub> = &gamma; v<sub>t-1</sub> - &alpha; &nabla;L(w<sub>t</sub>)
                </div>
                <p style="font-size: 0.9rem; margin-top: 10px;">
                    <strong>Understanding Beta/Gamma (&gamma;):</strong> This parameter acts as "friction" or memory.
                    <br>&bull; <strong>High &gamma; (0.9):</strong> The agent keeps 90% of its previous speed. It's like a heavy truck; it punches through small bumps but takes longer to turn.
                    <br>&bull; <strong>Low &gamma; (0.5):</strong> The agent keeps only 50% of its speed. It's lighter and changes direction faster but gets stuck more easily.
                </p>
                <p style="font-size: 0.9rem; margin-top: 10px;"><strong>The Result:</strong> 
                <br>&bull; <strong>Vertical Direction:</strong> Gradients flip signs (+, -, +, -). Summing them causes cancellation ($1 + (-1) = 0$). The oscillation dampens.
                <br>&bull; <strong>Horizontal Direction:</strong> Gradients are small but consistent (+, +, +). Summing them builds velocity, accelerating down the valley.</p>
            </div>

            <div class="math-section">
                <h3>2. Why Adam usually beats Momentum</h3>
                <p><strong>The Problem:</strong> Momentum relies on a global Learning Rate (&alpha;). If the valley gets flatter, it slows down. If the gradient gets steeper, it can overshoot dangerously.</p>
                <div class="formula">
                    Step &approx; &alpha; &middot; m<sub>t</sub> / &radic;v<sub>t</sub>
                </div>
                <p style="font-size: 0.9rem; margin-top: 10px;">
                    <strong>Understanding Adam's Betas:</strong> Adam keeps two separate histories.
                    <br>&bull; <strong>&beta;<sub>1</sub> (Momentum):</strong> Tracks the <em>direction</em> (mean). Usually 0.9.
                    <br>&bull; <strong>&beta;<sub>2</sub> (Scaling):</strong> Tracks the <em>magnitude/volatility</em> (variance). Usually 0.999.
                    <br><strong>What changing &beta;<sub>2</sub> does:</strong> If you lower &beta;<sub>2</sub> (e.g., to 0.9), Adam forgets historical volatility faster. This makes it adapt to "new" terrain steepness very aggressively, which can sometimes be unstable.
                </p>
                <p style="font-size: 0.9rem; margin-top: 10px;"><strong>The Math:</strong> Adam divides the momentum (m<sub>t</sub>) by the root mean square of gradients (&radic;v<sub>t</sub>).
                <br>&bull; <strong>Steep Slopes:</strong> Gradient is large &rarr; &radic;v<sub>t</sub> is large &rarr; Step size decreases (Stabilizing).
                <br>&bull; <strong>Flat Valleys:</strong> Gradient is tiny &rarr; &radic;v<sub>t</sub> is tiny &rarr; Step size increases (Accelerating).
                </p>

    <script>
        // --- 1. CONFIGURATION & STATE ---
        const CONFIG = {
            startX: -1.5,
            startY: 2.0,
            range: { x: [-2, 2], y: [-1, 3] },
            stepsPerFrame: 5, 
            epsilon: 1e-8
        };

        let isRunning = false;
        let animationId = null;
        let iteration = 0;
        
        let historySGD = { dx: 0, dy: 0, oscCount: 0 };

        let agents = {
            sgd: { x: 0, y: 0, pathX: [], pathY: [], loss: 0 },
            mom: { x: 0, y: 0, vx: 0, vy: 0, pathX: [], pathY: [], loss: 0 },
            adam: { x: 0, y: 0, mX: 0, mY: 0, vX: 0, vY: 0, pathX: [], pathY: [], loss: 0 }
        };

        // --- 2. MATH: ROSENBROCK FUNCTION ---
        function getLoss(x, y) {
            return Math.pow(1 - x, 2) + 100 * Math.pow(y - x * x, 2);
        }

        function getGradients(x, y) {
            const dx = -2 * (1 - x) - 400 * x * (y - x * x);
            const dy = 200 * (y - x * x);
            return { dx, dy };
        }

        // --- 3. UI REFERENCES ---
        const ui = {
            lr: document.getElementById('lr'),
            mom: document.getElementById('momentum'),
            b1: document.getElementById('beta1'),
            b2: document.getElementById('beta2'),
            btn: document.getElementById('btn-start'),
            iter: document.getElementById('iter-count'),
            lossSGD: document.getElementById('loss-sgd'),
            lossMom: document.getElementById('loss-mom'),
            lossAdam: document.getElementById('loss-adam'),
            status: document.getElementById('status-text'),
            modal: document.getElementById('math-modal')
        };

        // --- 4. INTERACTION & EXPLANATION ---
        function toggleMathModal() {
            const modal = ui.modal;
            if (modal.style.display === "block") {
                modal.style.display = "none";
            } else {
                modal.style.display = "block";
            }
        }

        // Close modal when clicking outside
        window.onclick = function(event) {
            if (event.target == ui.modal) {
                ui.modal.style.display = "none";
            }
        }

        function updateStatusBox() {
            if (!isRunning && iteration === 0) return;

            let msg = "";
            const sgdLoss = agents.sgd.loss;
            const adamLoss = agents.adam.loss;
            const momLoss = agents.mom.loss;

            if (iteration < 20) {
                ui.status.innerHTML = "<strong>Early Phase:</strong> All agents move quickly down the steep gradient. Note how Momentum (Blue) builds up speed.";
                return;
            }

            let isOscillating = historySGD.oscCount > 5;
            if (isOscillating) {
                msg += "<span class='bad'>Warning: SGD Oscillation!</span><br>SGD is bouncing off the valley walls. The gradient is steep perpendicular to the path. <br><em>Try lowering Learning Rate or adding Momentum.</em><br><br>";
            } else {
                msg += "SGD is descending slowly. <br><br>";
            }

            if (adamLoss < momLoss && adamLoss < sgdLoss) {
                msg += "<span class='good'>Adam is winning.</span><br>Adam's adaptive learning rate scales down the step size in the steep direction (vertical) and scales it up in the flat direction (horizontal).";
            } else if (momLoss < adamLoss) {
                msg += "<span class='good'>Momentum is leading.</span><br>The accumulated velocity vector is helping it plow through the flat valley floor.";
            }

            if (adamLoss < 0.1) {
                msg = "<span class='good'>Target Acquired!</span><br>Adam has successfully navigated the curve. Notice how it didn't need a tiny learning rate to be stable.";
            }

            ui.status.innerHTML = msg;
        }

        ui.lr.addEventListener('input', (e) => {
            ui.status.innerHTML = `<strong>Learning Rate (${e.target.value}):</strong><br>Determines step size. <br>Too high = Oscillation/Divergence.<br>Too low = Slow convergence.`;
            document.getElementById('val-lr').innerText = e.target.value;
        });
        ui.mom.addEventListener('input', (e) => {
            ui.status.innerHTML = `<strong>Momentum (${e.target.value}):</strong><br>Like a heavy ball rolling down a hill. Helps dampen oscillations and pass through local minima.`;
            document.getElementById('val-mom').innerText = e.target.value;
        });
        ui.b1.addEventListener('input', (e) => {
             document.getElementById('val-b1').innerText = e.target.value;
        });
        ui.b2.addEventListener('input', (e) => {
             document.getElementById('val-b2').innerText = e.target.value;
        });


        // --- 5. CORE OPTIMIZATION LOOP ---
        function step() {
            const lr = parseFloat(ui.lr.value);
            const beta = parseFloat(ui.mom.value);
            const b1 = parseFloat(ui.b1.value);
            const b2 = parseFloat(ui.b2.value);
            
            iteration++;

            // SGD
            let g = getGradients(agents.sgd.x, agents.sgd.y);
            if (Math.sign(g.dx) !== Math.sign(historySGD.dx)) historySGD.oscCount++;
            else historySGD.oscCount = Math.max(0, historySGD.oscCount - 1);
            historySGD.dx = g.dx;

            agents.sgd.x -= lr * g.dx;
            agents.sgd.y -= lr * g.dy;
            agents.sgd.pathX.push(agents.sgd.x);
            agents.sgd.pathY.push(agents.sgd.y);
            agents.sgd.loss = getLoss(agents.sgd.x, agents.sgd.y);

            // MOMENTUM
            g = getGradients(agents.mom.x, agents.mom.y);
            agents.mom.vx = beta * agents.mom.vx - lr * g.dx;
            agents.mom.vy = beta * agents.mom.vy - lr * g.dy;
            agents.mom.x += agents.mom.vx;
            agents.mom.y += agents.mom.vy;
            agents.mom.pathX.push(agents.mom.x);
            agents.mom.pathY.push(agents.mom.y);
            agents.mom.loss = getLoss(agents.mom.x, agents.mom.y);

            // ADAM
            g = getGradients(agents.adam.x, agents.adam.y);
            
            agents.adam.mX = b1 * agents.adam.mX + (1 - b1) * g.dx;
            agents.adam.mY = b1 * agents.adam.mY + (1 - b1) * g.dy;
            
            agents.adam.vX = b2 * agents.adam.vX + (1 - b2) * (g.dx * g.dx);
            agents.adam.vY = b2 * agents.adam.vY + (1 - b2) * (g.dy * g.dy);
            
            let mHatX = agents.adam.mX / (1 - Math.pow(b1, iteration));
            let mHatY = agents.adam.mY / (1 - Math.pow(b1, iteration));
            let vHatX = agents.adam.vX / (1 - Math.pow(b2, iteration));
            let vHatY = agents.adam.vY / (1 - Math.pow(b2, iteration));

            agents.adam.x -= lr * mHatX / (Math.sqrt(vHatX) + CONFIG.epsilon);
            agents.adam.y -= lr * mHatY / (Math.sqrt(vHatY) + CONFIG.epsilon);
            
            agents.adam.pathX.push(agents.adam.x);
            agents.adam.pathY.push(agents.adam.y);
            agents.adam.loss = getLoss(agents.adam.x, agents.adam.y);
        }

        function updateDisplay() {
            ui.iter.innerText = iteration;
            ui.lossSGD.innerText = agents.sgd.loss.toFixed(4);
            ui.lossMom.innerText = agents.mom.loss.toFixed(4);
            ui.lossAdam.innerText = agents.adam.loss.toFixed(4);

            Plotly.extendTraces('plot', {
                x: [[agents.sgd.x], [agents.mom.x], [agents.adam.x]],
                y: [[agents.sgd.y], [agents.mom.y], [agents.adam.y]]
            }, [1, 2, 3]);
        }

        function animate() {
            if (!isRunning) return;
            for(let i=0; i<CONFIG.stepsPerFrame; i++) {
                step();
            }
            updateDisplay();
            if (iteration % (CONFIG.stepsPerFrame * 10) === 0) {
                updateStatusBox();
            }
            animationId = requestAnimationFrame(animate);
        }

        function toggleAnimation() {
            if (isRunning) {
                isRunning = false;
                cancelAnimationFrame(animationId);
                ui.btn.innerText = "Resume Race";
                ui.btn.style.backgroundColor = "#f39c12"; 
            } else {
                isRunning = true;
                ui.btn.innerText = "Pause";
                ui.btn.style.backgroundColor = "#e67e22"; 
                animate();
            }
        }

        function resetSimulation() {
            isRunning = false;
            cancelAnimationFrame(animationId);
            ui.btn.innerText = "Start Race";
            ui.btn.style.backgroundColor = "#27ae60"; 
            iteration = 0;
            historySGD = { dx: 0, dy: 0, oscCount: 0 };

            agents.sgd = { x: CONFIG.startX, y: CONFIG.startY, pathX: [CONFIG.startX], pathY: [CONFIG.startY], loss: getLoss(CONFIG.startX, CONFIG.startY) };
            agents.mom = { x: CONFIG.startX, y: CONFIG.startY, vx: 0, vy: 0, pathX: [CONFIG.startX], pathY: [CONFIG.startY], loss: getLoss(CONFIG.startX, CONFIG.startY) };
            agents.adam = { x: CONFIG.startX, y: CONFIG.startY, mX: 0, mY: 0, vX: 0, vY: 0, pathX: [CONFIG.startX], pathY: [CONFIG.startY], loss: getLoss(CONFIG.startX, CONFIG.startY) };

            initPlot();
            ui.iter.innerText = "0";
            ui.lossSGD.innerText = "0.00";
            ui.lossMom.innerText = "0.00";
            ui.lossAdam.innerText = "0.00";
            ui.status.innerHTML = "Welcome! This visualization shows why standard SGD struggles on complex surfaces. <br><br>Adjust the <span class='highlight'>Learning Rate</span> above, then click <strong>Start Race</strong> to begin.";
        }

        // --- 6. PLOT INITIALIZATION ---
        function generateContourData() {
            let x = [], y = [], z = [];
            let n = 100;
            let xStep = (CONFIG.range.x[1] - CONFIG.range.x[0]) / n;
            let yStep = (CONFIG.range.y[1] - CONFIG.range.y[0]) / n;

            for (let i = 0; i <= n; i++) x.push(CONFIG.range.x[0] + i * xStep);
            for (let i = 0; i <= n; i++) y.push(CONFIG.range.y[0] + i * yStep);

            for (let j = 0; j < y.length; j++) {
                let row = [];
                for (let i = 0; i < x.length; i++) {
                    row.push(Math.log(getLoss(x[i], y[j]) + 1));
                }
                z.push(row);
            }
            return { x, y, z };
        }

        function initPlot() {
            const data = generateContourData();

            const contourTrace = {
                z: data.z, x: data.x, y: data.y,
                type: 'contour',
                colorscale: 'Viridis',
                ncontours: 40,
                contours: { showlabels: false },
                hoverinfo: 'none',
                opacity: 0.6
            };

            const traceStyle = {
                mode: 'lines+markers', type: 'scatter',
                marker: { size: 8 }, line: { width: 3 }
            };

            const sgdTrace = { ...traceStyle, x: [CONFIG.startX], y: [CONFIG.startY], name: 'SGD', line: { color: 'red' }, marker: { color: 'red' } };
            const momTrace = { ...traceStyle, x: [CONFIG.startX], y: [CONFIG.startY], name: 'Momentum', line: { color: 'blue' }, marker: { color: 'blue' } };
            const adamTrace = { ...traceStyle, x: [CONFIG.startX], y: [CONFIG.startY], name: 'Adam', line: { color: 'lime' }, marker: { color: 'lime' } };
            
            const targetTrace = {
                x: [1], y: [1], mode: 'markers', type: 'scatter', name: 'Global Min',
                marker: { symbol: 'star', color: 'gold', size: 15, line: {color: 'black', width: 1} }
            };

            const layout = {
                title: 'Loss Surface (Rosenbrock)',
                xaxis: { range: CONFIG.range.x, title: 'X' },
                yaxis: { range: CONFIG.range.y, title: 'Y' },
                showlegend: true,
                legend: { x: 0, y: 1, bgcolor: 'rgba(255,255,255,0.7)' },
                margin: { l: 50, r: 20, t: 40, b: 40 }
            };

            Plotly.newPlot('plot', [contourTrace, sgdTrace, momTrace, adamTrace, targetTrace], layout, { responsive: true });
        }

        window.onload = () => {
            initPlot();
            resetSimulation();
        };
