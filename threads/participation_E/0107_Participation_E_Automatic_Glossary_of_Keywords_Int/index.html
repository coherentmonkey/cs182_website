Participation E: Automatic Glossary of Keywords Introduced in Lecture

By Sammie Smith 2025-10-03 Gemini
View on Ed Stem →
Hi everyone, I put together a small website that automatically builds a glossary from our lecture transcripts using (free!!!) API calls from Gemini-2.5-flash. The goal is to make it easier to keep track of technical terms, see plain-English definitions, and get beginner-friendly explanations of how those terms show up in machine learning and deep learning. 👉 Website link: https://sammiesmith.github.io/DL_glossaries_Smith.github.io/ How to use the site The Glossary page lists all the terms extracted from Lecture 1 (so far). You can search using the bar in the top-right (search is limited to the “Term” column). Each entry shows: the plain-English definition, the prerequisite material reference (when available), and a description of how the term is used in ML/DL. The Methods page explains how the glossary is generated (pipeline, prompts, limitations, and ideas for improvement). Why I built this Sometimes the hardest part of lecture is just keeping all the new vocabulary straight. My hope is this tool can give quick, reliable definitions and context, and eventually we could add features like quiz-me buttons for studying. Feel free to explore it and let me know if you run into bugs or have ideas for features that would make it more useful! — Sammie
