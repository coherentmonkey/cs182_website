Special Participation E: Follow Up on Using ChatGPT to Help Understand Papers

By Etaash Patel 2025-12-08 GPT
View on Ed Stem →
I wanted to revisit the issues raised in Post #284 and see whether we could get better results from ChatGPT by adjusting the setup. I repeated the same exercise, but with a few important differences: 1. Narrowed context. Instead of giving ChatGPT the entire paper (https://arxiv.org/pdf/2310.17813), I only provided the single page containing the claims and their justifications. 2. Revised prompt. I rewrote the prompt to directly address the concerns mentioned in Post #284. In particular, I emphasized that the explanation should be: self-contained, well structured, and written primarily in clear English prose. The full prompt is below: "Hello, I would like you to expand on the arguments given for the claims in a paper I am reading (A Spectral Condition ...). When doing so, could you please make sure your explanation is: A. Precise B. Easy to follow: proofs should be in English prose as much as possible (while still being precise) C. Self-Contained: Please try to only reference facts a CS182 student would know. If you need to include new facts/arguments, please state them in full before using them D. Well structured. Also, at the end, please try to generate some questions to check conceptual understanding." 3. Different models. I have a free trial of ChatGPT Pro, so I tested both the Pro model and the free model on the same prompt. Both were set to “Thinking Mode” before answering. Models were GPT 5 (for free version) and 5.1 (for paid version). Overall observations: Unsurprisingly, the Pro model produced a significantly stronger explanation. That said, I still found that the free model, after some coaxing, generated an explanation addressed some of the problems mentioned than the original response shown in Post #284. The one thing both models still suffer from is having a concise writeup (in both cases, the model's explanations are longer than needed). Much of this probably comes from the prompting though, as the prompt encourages the model to err on the side of too much detail. Both transcripts are attached below.
