Special Participation B: ChatGPT on HW7

By Faiaz Khan 2025-11-03 HW7 GPT
View on Ed Stem →
Evaluated ChatGPT‑5’s code for four HW7 coding tasks: (1) RNN & Gradients, (2) Last‑Name Classifier, (3) Autoencoders (vanilla/denoising/masked + viz + linear probe), (4) Graph‑Clustering (spectral). Bottom line: Very strong overall. Everything in RNN and Autoencoder sections matches staff intent; the Last‑Name Classifier is clean and vectorized. The only material issues are in Graph‑Clustering: Adjacency sign error. Used Aij​=exp(+γ∥xi​−xj​∥2) instead of the standard exp(−γ∥xi​−xj​∥2) with γ>0, inverting similarity and undermining spectral clustering. Degree‑matrix contract. A function named get_degree_matrix returned D−1/2 (inverse‑sqrt) rather than D; later steps still formed M=D−1/2AD−1/2 correctly, but the naming conflicts with the prompt/staff text and can confuse follow‑ups. Per‑task highlights: RNN & Gradients. RNNLayer uses two linears with a single bias on the input map, explicit unroll, and correct shapes. RecurrentRegressionModel applies a shared readout per timestep. Loss uses MSELoss and supports last_timestep_only. The gradient visualizer scales parameters and inspects the recurrent matrix Whh​ (right choice for exploding/vanishing diagnostics). Last‑Name Classifier. Clean pipeline: Embedding → RNN/LSTM (batch_first) → gather last_pos (vectorized) → Dropout → Linear logits. Hyperparameters (2×256 LSTM, dropout 0.30, Adam 3e−3, grad‑clip 5) are plausible for the ≥80% @20 epochs target. Ethical‑use answer is thoughtful (proxy discrimination, surveillance, privacy, overconfidence) and aligned with staff emphasis on responsible deployment. Autoencoders. Decoder is symmetric (no final activation); forward/MSELoss match the objective. Denoising AE adds Gaussian noise and reconstructs the clean input; Masked AE computes masked MSE on unmasked positions only. The evaluation helper encodes features, applies a linear probe, and computes accuracy with no_grad(). The plotting helper produces mean‑with‑markers + min–max band per epoch as specified. Graph‑Clustering. The spectral pipeline (SVD on M, use U[:,:3]​, row‑normalize, then KMeans) is correct and the commentary identifies standard pitfalls (γ scaling, need for row‑norm). However, the RBF sign must be negative and the degree matrix function should either return D (per prompt) or be clearly renamed if returning D−1/2. Fixing these yields behavior that matches the staff solution.
