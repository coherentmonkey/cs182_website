I used the Cursor IDE on the coding portion of HW 1. Executive Summary: Cursor was overall highly effective at solving the coding problems in this homework. It required very little context supplied by me through the chat thread, as it was able to retrieve context from code cells and even visualizations (i.e. training plots) on its own. It successfully connected logical/programming reasoning, numerical reasoning, and visual reasoning to even answer conceptual questions within the coding portion of the homework. Its largest failure mode, however, was lacking the ability to fully engage with the jupyter notebook, as it could not run cells autonomously the way it can run standard code files. This inhibited its iterative design process—it could not continuously cycle between writing new code, running it, seeing the result, and making adjustments as needed—so it therefore required a bit more hand-holding towards the end of the assignment where this became an issue. However, Cursor was overall a strong tool in completing this homework, and it provided clear explanations that would be helpful to anyone who might be stuck conceptually on the problems.
