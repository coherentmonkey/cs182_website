Special Participation B: Kimi on HW7 Coding Tasks

By John Chang 2025-12-05 HW7 Kimi
View on Ed Stem →
For this task, I decided to use Kimi on the coding tasks for Homework 7. This homework had a good amount of coding with different tasks presented, including implementing equations and model architectures, fine-tuning hyperparameters, and producing graphs for model training. My methodology was to give Kimi only the code and tell it to complete the TODO sections. If it struggled, I would provide it with more context from the previous cell's text. (For problem 5, I always gave Kimi the previous cell's context because the code was very barebones with no comments). Overall, Kimi ran into a couple issues with some tasks -- implementing the squared loss for the autoencoder and implementing the masked autoencoder. It ultimately failed to implement the masked autoencoder due to its code not accounting for how random initialization would work in Colab. For most tasks, it was able to one-shot a solution. For model training tasks, Kimi was able to one-shot the last-name RNN and provided code that brought the autoencoder up to 77% accuracy on MNIST (I just had to increase the epochs by 10). It was also able to correctly implement the graph-perspective notebook and achieve ideal separation between the three real distributions.
