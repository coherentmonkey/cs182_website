● Looking at the NumpyTransformer forward pass and the hint in the markdown,
   here's how to implement the vectorized forward pass:

  def forward(self, seq):
      # Concatenate positional encodings if they exist
      if self.pos is not None:
          seq_len = seq.shape[0]
          positions = torch.arange(seq_len, device=seq.device)
          pos_enc = self.pos(positions)  # (seq_len, pos_dim)
          seq = torch.cat([seq, pos_enc], dim=-1)  # (seq_len, input_dim + 
  pos_dim)

      # Compute Q, K, V projections
      Q = self.Qm(seq)  # (seq_len, qk_dim)
      K = self.Km(seq)  # (seq_len, qk_dim)
      V = self.Vm(seq)  # (seq_len, v_dim)

      # Compute attention scores: QK^T / sqrt(d_k)
      scores = Q @ K.T / math.sqrt(self.d_k)  # (seq_len, seq_len)

      # Apply softmax along the last dimension (each query attends to all 
  keys)
      attn_weights = torch.softmax(scores, dim=-1)  # (seq_len, seq_len)

      # Compute output: weighted sum of values
      out = attn_weights @ V  # (seq_len, v_dim)

      return out

  Step-by-step explanation:

  1. Positional encoding: If self.pos exists (it's an nn.Embedding), create
  indices [0, 1, 2, ..., seq_len-1] and look up the embeddings. Concatenate
  them to the input sequence along the last dimension.
  2. Q, K, V projections: Pass the (possibly augmented) sequence through the
   linear layers to get queries, keys, and values.
  3. Attention scores: Compute Q @ K.T to get a (seq_len, seq_len) matrix
  where entry [i, j] is the dot product between query i and key j. Divide by
   sqrt(d_k) for scaling.
  4. Softmax: Apply softmax along dim=-1 so each row (query) has attention
  weights that sum to 1.
  5. Output: Multiply attention weights by values to get the final output of
   shape (seq_len, v_dim).

● Looking at cell-21, the task is to output positive for unique tokens and
  negative for repeated tokens. The strategy:
  1. Content-based attention to find same-content tokens
  2. Position-based self-exclusion (don't attend to yourself)
  3. CLS token provides positive offset value

  pos = np.eye(5)  # shape (5, 5), one-hot positional encoding

  # Km: content matching + position (positive)
  Km = np.zeros((9, 9))
  Km[:4, :4] = 10 * np.eye(4)   # content dims
  Km[4:, 4:] = 20 * np.eye(5)   # position dims

  # Qm: content matching + position (negative for self-exclusion)
  Qm = np.zeros((9, 9))
  Qm[:4, :4] = 10 * np.eye(4)   # content dims
  Qm[4:, 4:] = -20 * np.eye(5)  # position dims (negative to mask self)

  # Vm: CLS (index 3) gives positive, A/B/C give negative
  Vm = np.array([[-1], [-1], [-1], [5], [0], [0], [0], [0], [0]])

  Why this works:
  - Same content + different position → high score (100)
  - Same content + same position → very negative (-300), effectively masked
  - Different content → score of 0
  - Unique token: attention spreads to CLS and others → positive output
  - Repeated token: attention focuses on other same-content tokens →
  negative output
