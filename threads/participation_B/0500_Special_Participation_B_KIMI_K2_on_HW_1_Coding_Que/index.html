Special Participation B: KIMI K2 on HW 1 Coding Questions

By Qicheng Zhu 2025-12-05 HW1 Kimi
View on Ed Stem →
Model Tested: KIMI K2 Domain: Homework1 Coding part -- Accelerating Gradient Descent with Momentum Performance Overview: In this experiment, I evaluated the performance of KIMI K2 on a deep learning homework task that involved implementing and analyzing gradient descent with momentum. The homework consisted of two main coding parts: The first part is implementing gradient descent with momentum. The second part is exploring learning rate for faster convergence. To assess model robustness, I designed two experiments to explore the importance of background knowledge: Experiment 1: No Background Knowledge The model was prompted directly with coding tasks, without any formulas or context. The solution was partially correct, but there were subtle differences. KIMI K2 used a slightly different formulation for momentum (using different coefficient). The code still worked, but was not fully aligned with the provided formula. Experiment 2: With Background Knowledge I provided KIMI K2 with the correct mathematical equations for momentum before asking the question again. After receiving the formulas, the model produced the correct implementation. This suggests that additional mathematical grounding improves reliability. I further tested whether the input format affects performance. I supplied the same task using jupyter notebook or screenshots photos. In each case, KIMI K2 successfully generated the correct answer, indicating strong multimodal consistency. Overall, KIMI K2 can correctly solve non-trivial coding questions involving optimization algorithms. The model benefits from being given mathematical context, but once the formulas are provided, it can generalize across multiple input formats.
